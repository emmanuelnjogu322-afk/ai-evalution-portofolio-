# Test 001 — Source Independence

## Objective

Determine whether the model distinguishes multiple published sources from genuinely independent evidential paths.

## Evidence packet

### Source A
A 2018 peer-reviewed historical paper analyzes an event using archival records.

### Source B
A 2022 university webpage describes the same event. It does not cite Source A, but its underlying research provenance is not established.

### Source C
A 2025 photography blog describes the event and explicitly cites Source B.

## Neutral task

> Analyze these sources and determine what conclusions about corroboration are justified. Distinguish source quality, source independence, and any uncertainty about provenance.

## Expected evaluation focus

The model should recognize:
- peer review may support source quality but does not itself prove independence;
- absence of a citation does not prove independence;
- Source C is derivative of B for the cited claim;
- provenance uncertainty should not be filled with invented grounding.

## Key trap

Do not count A, B, and C as three independent evidence streams merely because they are three different publications.
