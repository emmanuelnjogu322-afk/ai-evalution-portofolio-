# Evidence Lineage Model

## Purpose

Evidence lineage tracks how a claim is connected to its underlying evidence.

A source should not receive independent-evidence credit merely because it is a different document, website, publication type, or author.

## Lineage model

**Source → provenance → underlying evidence → analysis → interpretation → conclusion → confidence**

### Source
What document or record contains the information?

### Provenance
Where did that source obtain the information?

### Underlying evidence
What observation, record, document, dataset, or primary material ultimately supports the claim?

### Analysis
How was the underlying evidence examined?

### Interpretation
What meaning is being assigned to the evidence?

### Conclusion
What proposition is being asserted?

### Confidence
How strongly does the available evidence justify the conclusion?

## Independence

### Independent evidential path

A source provides an evidential path that does not simply reproduce the same underlying source or reporting chain used by another source.

### Independent analysis

Two researchers may independently analyze the same underlying primary evidence. Their analyses can therefore be independent even though the underlying evidence is shared.

This is different from having two independent pieces of evidence.

### Derivative source

A later source that obtains its claim from an earlier source does not become an independent evidential path merely because it uses different wording or appears in a different publication.

## Examples

### Derivative chain

**Source A → Source B → Source C → Claim**

If B relies on A and C relies on B, three documents do not represent three independent evidence streams.

### Independent analyses of shared evidence

**Primary Evidence → Analysis A → Conclusion A**

**Primary Evidence → Analysis B → Conclusion B**

A and B are independent analyses, but the underlying evidence remains shared.

### Stronger corroboration

**Primary Evidence A → Conclusion**

**Primary Evidence B → Conclusion**

Different underlying evidence provides a stronger basis for independent evidential corroboration, assuming both sources are authentic and relevant.

## Agent requirements

For evidence-sensitive research, the agent should:

1. identify the source;
2. trace provenance where possible;
3. identify the underlying evidence;
4. distinguish evidence from interpretation;
5. distinguish independent analysis from independent evidence;
6. flag unresolved provenance;
7. avoid inventing missing source relationships;
8. avoid counting derivative sources as independent corroboration.

## Important limitation

Failure to find a citation relationship does not prove that two sources are independent.

Likewise, peer review or institutional publication may strengthen source quality without proving independence.

The agent should report what it can establish and label what remains uncertain.
