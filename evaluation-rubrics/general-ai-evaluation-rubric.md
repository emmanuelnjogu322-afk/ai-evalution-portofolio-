# General AI Evaluation Rubric

A working framework for evaluating AI-generated responses.

| Dimension | Core question |
|---|---|
| Accuracy | Are factual claims correct and supported? |
| Relevance | Does the response address the actual task? |
| Completeness | Are important requirements covered? |
| Reasoning | Do conclusions follow logically from evidence? |
| Clarity | Is the response understandable and structured? |
| Reliability | Does it distinguish facts, uncertainty, and unsupported claims? |
| Instruction-following | Did it respect explicit constraints? |

## Severity

- **Minor** — limited impact.
- **Major** — materially affects correctness, completeness, reliability, or task fulfillment.
- **Critical** — substantial risk of serious misinformation, unsafe action, or fundamental task failure.
