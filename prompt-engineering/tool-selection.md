# Tool Selection

Match a task to the capability that can perform it reliably.

- **Web search** — current or externally verifiable information
- **Retrieval** — information contained in a known document or knowledge base
- **Calculator** — arithmetic and numerical transformations
- **Data analysis** — structured quantitative exploration
- **Document tools** — extracting or transforming file content

A tool should be selected because it materially improves correctness, evidence quality, or task completion.
